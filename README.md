# Dragger
퍼블리싱에 대한 죄책감을 덜어주는 서비스.

디자이너처럼 코드를 직접 다루지 않는 사람이 웹 화면의 간격·글자·색상을 바꾸고, 수정안을 개발팀에 전달하는 도구입니다. 화면에서 편집한 값을 원본 코드에 적용하고, GitHub 또는 Bitbucket에서 검토를 요청할 수 있습니다.

**처음 연결은 내 컴퓨터에서 작업할 수 있는 AI에게 맡기고, 이후에는 화면에서 편집하세요.** 코드나 터미널 명령어를 미리 배울 필요는 없습니다. 현재는 초기 버전이며, React / Next.js webpack 기반 앱의 연결을 지원합니다. 모든 사이트의 주소만 넣으면 편집되는 제품은 아닙니다.

## 1. 내려받고 AI에게 설치 맡기기

[다운로드 페이지](https://github.com/JinSEONGYEE/Dragger/releases)에서 가장 최근 버전의 **Dragger-MCP-…zip**을 받아 압축을 풉니다.

파일을 읽고 프로그램을 실행할 수 있는 AI 코딩 도구에 압축을 푼 Dragger 폴더를 열어 주세요. 웹 채팅만 가능한 AI라면 컴퓨터에서 설치 작업을 대신할 수 없습니다. 다음 요청을 복사해서 보내세요.

```text
나는 코드를 직접 다루지 않는 사용자야. 이 폴더의 README.md와 docs/AI-SETUP.md를 읽고 Dragger 설치와 내 앱 연결을 진행해 줘.

필요한 프로그램 확인, 앱 실행, 모든 페이지에 공통으로 적용되는 편집 연결, Dragger 등록까지 직접 해 줘. 내가 모를 만한 경로나 명령어는 직접 찾아서 처리해 줘.
내가 편집할 서비스가 무엇인지, 원본 코드가 어디 있는지 먼저 확인해 줘. 정보가 없으면 추측하지 말고 꼭 필요한 것만 쉬운 말로 물어봐 줘.
로그인과 토큰 입력은 내가 해당 서비스 화면에서 할게. 실제 연결이 안 되면 샘플 데이터로 대신하고 성공했다고 말하지 마.
끝나면 편집기를 열고 실제 페이지 이동과 요소 선택을 확인해 줘. 다음번에는 어떤 파일을 열면 되는지도 알려줘. PR 업로드는 내가 요청할 때 해 줘.
```

AI가 서비스 이름, GitHub·Bitbucket 저장소 주소 또는 이미 받은 서비스 폴더를 물어보면 알려 주세요. 저장소는 **서비스의 원본 코드 보관함**입니다. Dragger를 받은 폴더와 편집할 서비스의 폴더는 서로 다릅니다.

AI가 설치를 대신할 수 없는 경우, [Node.js 공식 다운로드](https://nodejs.org/en/download)에서 LTS로 표시된 버전의 내 운영체제용 설치 파일을 받아 설치하세요. Node.js는 Dragger를 실행하는 프로그램이며 20 이상이 필요합니다. 설치한 뒤 AI 앱이나 실행 창을 다시 열어 주세요. 회사에서 프로그램 설치를 제한한 컴퓨터는 회사의 승인 절차를 따라야 합니다.

## 2. 다음부터는 시작 파일 열기

압축을 푼 폴더 안에서 다음 파일을 엽니다.

| 내 컴퓨터 | 열 파일 |
| --- | --- |
| Mac | `Dragger 시작.command` |
| Windows | `Start-Dragger.cmd` |

브라우저에 Dragger가 열립니다. 실행 창을 닫으면 연결도 끊어지므로 편집 중에는 열어 두세요. 편집할 서비스도 실행 중이어야 합니다. 최초 연결을 맡긴 AI에게 서비스 실행 방법도 함께 정리해 달라고 요청하세요.

처음 연결 화면에서 **AI에게 연결 맡기기 → AI 요청 복사**를 누르면 현재 등록 정보가 포함된 요청을 만들 수 있습니다. MCP는 AI가 Dragger 상태와 수정안을 읽는 선택 기능입니다. 직접 설정법을 배울 필요 없이 같은 AI에게 설치를 맡기면 됩니다.

이미 팀에서 연결 파일을 받았다면 **팀 연결 파일 불러오기**를 사용하세요. 앱 실행이나 원본 폴더 준비가 생략되는 것은 아니므로 모르는 입력값은 AI에게 확인해 달라고 요청하면 됩니다.

## 3. 화면을 이동하며 편집하기

1. **서비스 연결 → 시작하기 · 연결 상태**를 엽니다. 앱 주소를 등록하면 나타나는 **연결한 서비스 새 탭에서 열기**를 누르세요. 새 탭에 열린 서비스에서 해당 서비스 계정으로 로그인합니다. Dragger와 같은 브라우저에서 진행하세요.
2. Dragger로 돌아와 **편집 화면 열기**를 누릅니다. 편집 패널을 닫은 상태에서는 평소처럼 앱 메뉴를 누르며 페이지를 이동할 수 있습니다.
3. 원하는 페이지에서 **UI 편집하기**를 켜고 수정할 요소를 클릭합니다.
4. 너비·간격·글자·색상을 수정합니다. 숫자를 입력하거나 슬라이더를 움직일 수 있습니다.
5. 잘못 바꿨다면 **편집 → 실행 취소**, 선택한 요소만 초기화하려면 **선택 요소 원래대로**를 사용합니다.

**편집 범위**는 기본적으로 **선택한 요소만**입니다. 공용 버튼·아이콘 등의 기본값을 바꾸려면 **공용 컴포넌트**를 선택하세요. 범위를 바꾸면 이후 수정값부터 적용되며, 다른 사용처는 코드 적용 후 반영됩니다. 하나의 요소만 안전하게 분리할 수 없으면 Dragger가 코드 적용을 중단합니다.

## 수정안을 개발팀에 보내기

**최종 검토 → 코드 변경 확인 → 코드 적용 및 확인 → 초안 PR 만들기** 순서로 진행합니다. 화면에 표시된 변경 파일과 내용을 확인하세요.

PR은 **“이 수정안을 확인하고 반영해 주세요”라는 검토 요청**입니다. 서비스가 바로 배포되는 것은 아닙니다. 처음 보낼 때 GitHub 또는 Bitbucket을 연결하고, 열린 웹페이지에서 PR을 최종 등록합니다. PR 작성 화면을 열었다는 것만으로 등록이 완료되지는 않습니다.

원본 코드까지 적용한 뒤 취소하려면 **코드 되돌리고 편집 계속**을 사용하세요. 이미 업로드한 수정안은 GitHub·Bitbucket에서 확인해야 합니다.

## 막혔을 때

| 보이는 상황 | 내가 할 일 |
| --- | --- |
| Node.js가 없다고 나옴 | 위 공식 설치 파일로 설치하거나 AI에게 설치를 맡긴 뒤 시작 파일을 다시 열기 |
| 127.0.0.1 연결 거부 | Dragger와 서비스 실행 창이 켜져 있는지 확인. AI에게 “기존 설정을 유지하고 두 프로그램을 다시 실행해 줘”라고 요청 |
| 원본 폴더를 모르겠음 | “내 서비스 코드를 내려받은 폴더를 찾아 Dragger에 등록해 줘”라고 AI에게 요청 |
| 화면은 뜨는데 선택이 안 됨 | 연결 화면의 AI 요청을 복사해서 전달. 화면과 코드의 연결이 준비됐는지 확인 요청 |
| 질문 수가 0이거나 답변·목록이 비어 있음 | 앱의 계정과 실제 데이터 연결 확인. 샘플 미리보기에서는 실제 질문·답변이 동작하지 않을 수 있음 |
| 로그인·접근 권한이 없음 | 회사의 계정·저장소 담당자에게 테스트 계정 또는 접근 권한 요청 |
| 코드 적용을 중단했다는 안내 | 변경은 보관한 채 오류 문구를 AI에게 전달. 모호한 원본을 억지로 수정하지 않기 |

## 혼자 준비할 수 있는 것과 회사에 받아야 하는 것

설치, 폴더 찾기, 앱 실행 명령 확인, 편집 연결 코드 설정은 권한과 환경이 갖춰져 있으면 AI가 도와줄 수 있습니다. 개발자에게 매 단계 작업을 부탁하는 것이 기본 흐름은 아닙니다.

다만 회사 코드 접근 권한, 개발용 서버 설정, 테스트 계정·데이터는 Dragger나 AI가 만들어 낼 수 없습니다. 없는 경우 담당자에게 한 번 받아야 합니다. 보낼 문장은 아래처럼 짧아도 됩니다.

> UI 수정안을 Dragger로 만들어 PR로 보내려고 합니다. 서비스 코드 접근 권한과 개발용 실행 설정, 테스트 계정을 받을 수 있을까요? 설치와 연결 작업은 AI로 진행하려고 합니다.

내 계정이 볼 수 있는 페이지와 데이터 범위에서 편집합니다. 화면이 열린다는 사실만으로 모든 페이지가 연결·검증됐다는 뜻은 아닙니다. 현재는 설치와 연결을 완전히 자동으로 끝내는 독립 설치 앱이 아니며, AI의 파일·명령 실행 기능이 준비를 보조합니다.

## 저장과 개인정보

수정 초안과 연결 정보는 사용 중인 컴퓨터·브라우저에 보관됩니다. 브라우저 데이터를 지우면 초안이 사라질 수 있습니다. 인증 토큰은 연결 화면에서 직접 입력하며 서버 재시작 후 다시 입력할 수 있습니다. 토큰이나 비밀번호를 AI 채팅에 붙여넣지 마세요.

AI에게 수정안 검토를 맡기면 코드와 텍스트가 해당 AI에 전달될 수 있습니다. 회사에서 허용한 AI와 계정을 사용하세요.
